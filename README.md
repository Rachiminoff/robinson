# Robinson

### typography × geometry × music

An experimental lyric experience inspired by **Spitz – Robinson**.

</div>

---

A small project exploring how lyrics, motion, and simple geometric forms can tell a story without using images.

### Stack

- React
- TypeScript
- Tailwind CSS
- Framer Motion
- Web Audio API

### Run locally

```bash
npm install
npm run dev
```
