# Visual System

## Design Direction

Robinson uses a visual language influenced by:

-   Swiss International Typographic Style
-   Bauhaus
-   editorial poster design
-   kinetic typography
-   modern motion graphics

The project should feel structured, intentional, and graphic.

------------------------------------------------------------------------

## 1. Grid

A grid provides structure even when the final composition appears
asymmetric.

The grid does not need to be visible.

It is mainly a way to decide:

-   alignment
-   spacing
-   margins
-   columns
-   visual rhythm

------------------------------------------------------------------------

## 2. Asymmetry

The composition should not always place everything in the center.

Useful alternatives include:

-   heavy left side
-   heavy right side
-   top-weighted composition
-   bottom-weighted composition
-   narrow vertical spine
-   offset block
-   cropped corner
-   large empty area with a small counterweight

Asymmetry creates tension while the underlying grid keeps the design
controlled.

------------------------------------------------------------------------

## 3. Scale

Use meaningful differences in size.

For example:

``` text
very large shape
+
medium supporting shape
+
small detail
```

This gives the viewer a visual hierarchy.

Avoid making every shape the same size.

------------------------------------------------------------------------

## 4. Cropping

A shape does not always need to be fully visible.

A circle can extend beyond an edge.

A block can start outside the viewport.

A diagonal field can cross the frame.

Cropping makes the composition feel like part of a larger poster rather
than a collection of objects placed inside a box.

------------------------------------------------------------------------

## 5. Negative Space

Empty space is part of the design.

Do not fill every available area.

Negative space gives the lyric room to breathe and creates contrast
against dense compositions.

------------------------------------------------------------------------

## 6. Typography

Typography is one of the main visual elements.

It should not feel like a label placed on top of the artwork.

Consider:

-   size
-   line length
-   alignment
-   weight
-   tracking
-   line height
-   vertical placement
-   relationship to geometric forms

The lyric should feel embedded in the composition.

------------------------------------------------------------------------

## 7. Shape Relationships

Shapes should interact.

Examples:

``` text
large red field
    ↓
small blue counterform
    ↓
thin black rule
```

or:

``` text
vertical spine
    +
cropped circle
    +
large lyric
```

The shapes should create a visual conversation.

Avoid unrelated decorative objects.

------------------------------------------------------------------------

## 8. Color Hierarchy

A palette should normally have:

-   a dominant field
-   a supporting color
-   an accent
-   an ink/text color

Not every color needs equal visual weight.

------------------------------------------------------------------------

## 9. Motion

Motion should reinforce the composition.

Good motion examples:

-   a block sliding into its grid position
-   typography revealing along an editorial axis
-   a circle expanding into a crop
-   a rule drawing across the composition
-   a field shifting during a lyric change

Avoid excessive effects such as:

-   random bouncing
-   unnecessary glowing
-   constant spinning
-   decorative UI-like bars
-   effects that compete with the lyrics

------------------------------------------------------------------------

## 10. Transition Philosophy

A transition should feel like one poster becoming another.

A useful mental model is:

``` text
Poster A
   ↓
shared visual element moves / changes
   ↓
Poster B
```

rather than:

``` text
Poster A
   ↓
generic fade
   ↓
Poster B
```

A simple transition can still be effective if the composition itself
provides continuity.
